[Home Assistant](https://www.home-assistant.io/) 毫米波雷达校准与实时可视化卡片，
支持 16 款雷达型号。

## 这是什么

一张房间俯视图，显示人实际在哪；以及把这张图变准的工具 —— 你告诉卡片雷达装在哪、朝哪，
画出房间边界，它就把雷达的原始输出换算成真实房间坐标。

这张卡片也是整个项目**唯一的用户界面**：校准在这里做，ESPHome 固件和融合集成都不自带界面。

对于一维测距雷达，目标轨迹、距离圆弧和米制刻度共用雷达法线及房间坐标投影。预览区域非等比缩放时，距离圆弧会呈椭圆形，以保持与房间坐标一致。

_(标签页 ① —— 几何与边界 | 标签页 ② —— 偏航校准 | 标签页 ③ —— 实时视图)_

## 快速开始

### 1. 通过 HACS 安装

[![Open your Home Assistant instance and open a repository inside HACS.](https://my.home-assistant.io/badges/hacs_repository.svg)](https://my.home-assistant.io/redirect/hacs_repository/?owner=zomco&repository=mmwave-card&category=plugin)

或者：**HACS → 前端 Frontend → ⋮ → 自定义仓库** → 添加本仓库 URL → 类别选
**Lovelace**。装完重启 Home Assistant。

### 2. 添加到面板

编辑任意面板 → **添加卡片** → 搜索 **MMWave Radar Card**。在下拉框里选型号，编辑器会
按型号列出需要的实体选择器，并已过滤好候选项。**完全不用写 YAML。**

### 3. 校准

按顺序做完三个标签页 —— 这一步决定坐标有没有意义，也是最多人跳过的一步：

| 标签页       | 做什么                                       | 为什么                                               |
| ------------ | -------------------------------------------- | ---------------------------------------------------- |
| ① 几何与边界 | 填写雷达位置（离墙角多少厘米），拖出房间轮廓 | 轮廓外的目标不再触发存在检测 —— 这就是穿墙幽灵的解法 |
| ② 偏航校准   | 依次在至少三个引导区域中心附近停留                 | 解算雷达朝向                                         |
| ③ 实时视图   | 走动几步看那个点                             | 验证前两步                                           |

点是镜像的说明偏航角差 180°；点和你的移动方向成直角说明差 90°。这时回标签页 ② 重做，
不要手动去凑数值。

> **还没烧固件？** 完整流程（接线 → 浏览器烧录 → 装这张卡片）见
> [新手上手指南](https://github.com/zomco/mmwave-component/blob/main/GETTING-STARTED_CN.md)。

## 多雷达融合（可选，实验性）

**单雷达无需任何额外安装，本卡片即可完整使用。**

如果要用多台雷达覆盖同一空间，并且需要轨迹持久化、区域事件和摄像头录像，那还需要装
**[mmwave-fusion](https://github.com/zomco/mmwave-fusion)** 集成 —— 它在 HACS 中是
独立的一项，类别为 **integration**。

未安装时，卡片仍会渲染融合视图，但融合只发生在浏览器内、不保存任何数据 —— 此时卡片会
明确提示"未安装融合集成"，而不是假装一切正常。

两者独立发版，因此集成会在每次推送里带上 `api_version`，卡片发现后端版本低于所需时会
直接提示升级。

可视化编辑器把雷达绑定、精确安装数值和共享 3D 安装场景合并在同一个配置步骤中，并以雷达
TAB 分页；当前 TAB 只显示一台雷达的表单和同步 3D 模型，添加雷达会创建并选中新 TAB。随后，
单雷达与融合方向校准共用绿色、等比例的户型图。依次在至少三个相距较远的区域停留，
每处连续采集三秒；站位允许约一个小步的偏差，不要求厘米级定位。推荐位置不可达时，
点击空白处可移动当前未采集区域。房间只留一名测试人员，多目标歧义和高波动采样会跳过。
每台雷达分别判断：至少三个有效站点、跨度 120 cm、均方根残差不超过 60 cm、最大残差
不超过 90 cm。加权拟合考虑约 30 cm 的站位误差，并保留俯仰及横滚；四个及以上站点中，
只有至少三点且占比 75% 的一致数据支持时才剔除明显异常站点。
原参数的均方根残差不超过 40 cm、最大残差不超过 60 cm，且新拟合改善不足 15 cm 时，
保留原参数并提示已通过检查，避免追逐测量噪声；不宣称存在唯一的物理最优值。
合格设备可先进入验证，未完成设备保留原配置并持续提示。补采时保留同一区域已完成设备
的数据；要完全重采，可先在详情中移除该区域。采集结果在“应用并同步”成功前仍是草稿，
请在实时验证中走到其他位置检查对齐效果，设备同步失败会单独显示。
在手机宽度下，校准面板提供移动专注模式：当前区域指引固定在顶部，大尺寸采集按钮固定在
底部安全区上方，实时进度就地更新，采集点与拟合诊断则默认折叠。这样测试人员可以单手持机
边走边完成采集，需要排查时再展开完整结果。
完成至少 3 点采集后，结果区会逐台对比当前 X/Y/yaw、拟合参考值和建议手动调整量；未通过的
拟合会标为低可信度并说明具体原因，便于先核对安装参数再重采，而不会把异常参考值自动写入配置。

融合状态、回放、热力图、覆盖范围和在线雷达数统一显示在户型画布外的工具栏中，不再遮挡
部署在边界上的雷达标识。

## 许可证

MIT © zomco

雷达预览以绿色虚线标出已配置的多边形边界，并将边界外区域标为灰色，便于理解软件边界过滤。界外目标仍显示，方便排查；未配置至少三个顶点时不显示多边形过滤叠层。

仅测距雷达使用软件距离区间（厘米，0 关闭对应限制），不再使用房间多边形。同步会写入设备的 Zone Min/Max Distance 实体。预览显示径向界限，以及可回读的原生最远范围；未知的原生最近范围或距离门屏蔽不视为已验证覆盖。保留原生检测阈值，不在启动时自动重置用户校准参数。

仅测距卡片直接在预览扇形中展示软件距离区间：绿色为保留区域，灰色环带为排除区域。详细范围诊断保留在设置中，不再显示于预览下方。

实时预览在卡片高度受限时仍保持横纵等比例缩放，通过留白避免雷达扇形被拉伸。目标、轨迹和边界使用同一映射，不改变保存的房间尺寸或安装参数。

### 户型背景

在卡片编辑器展开“户型背景”，填写图片地址，例如 `/local/floorplans/room.png`。
图片放在 HA 的 `/config/www/floorplans/room.png`；本开发环境对应
`ha-config/www/floorplans/room.png`。本版使用图片地址，不提供文件上传。支持 PNG、JPG、
WebP，建议使用无透视的俯视平面图。

取消“锁定位置”后可以拖动图片、调整旋转和偏移。“标定比例”允许点选已知墙段的两端，
输入实际长度（厘米）；“设置原点”将所选图片位置对应到房间左上角坐标原点。调整好后
锁定，并在 HA 中保存卡片。显示开关和不透明度仍可调整。

单雷达、融合预览、方向校准和安装定位的地面共用户型图。图片保持长宽比，使用房间坐标
定位，手机与桌面缩放不会改变对应关系。背景配置保存在 Lovelace 卡片中，不写入雷达固件；
同一融合卡片内所有雷达共用一张背景图。图片不会自动改变检测过滤，请另外绘制房间多边形。
图片加载失败时仍保留原有网格和雷达显示。

```yaml
floorplan:
  url: /local/floorplans/room.png
  width_cm: 600
  offset_x_cm: 0
  offset_y_cm: 0
  rotation: 0 # 以图片左上角为中心顺时针旋转，单位度
  opacity: 0.45
  visible: true
  locked: true
```

`width_cm` 表示整张图片（包括留白）对应的实际宽度，高度由图片比例自动确定；
偏移表示图片左上角在房间坐标中的位置。未填宽度时使用房间宽度。其他卡片要使用
相同的背景定位，可以复制整段 `floorplan` 配置。

在 **户型背景** 中直接上传 PNG、JPEG 或 GIF（小于 9 MB），图片由 Home Assistant 保存；保存卡片后即可保留图片地址，无需融合后端。编辑房间边界或融合区域时，开启 **沿墙吸附**，依次点击墙角附近，落点会吸附到附近图像轮廓。可撤销重选，检查后再保存。家具或文字也可能被识别为轮廓，可关闭吸附手动选点；外部链接图片可能需要重新上传才能吸附。

方向校准会将整个引导停留圆限制在已配置的房间边界内，并留出靠墙余量，手动移动也遵循相同限制。多雷达使用已配置雷达边界的可用区域；事件区域不作为房间边界。未配置多边形时按房间尺寸布点。边界中未体现的家具和障碍物无法自动识别，可手动将停留点移到空旷处；空间不足时显示提示，不再向边界外补点。

雷达预览图右下角按型号显示场景指标：LD2450A 显示手势（`gesture_entity`），LD6002、R60ABD1 等支持型号显示呼吸频率和心率（`breath_entity`、`heart_entity`）。可在卡片编辑器中绑定这些可选传感器；未绑定、不可用或无有效频率读数时显示“—”。
