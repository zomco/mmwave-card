# MMWave 视觉规范

[English](visual-language.md)

MMWave Card、卡片内的 Fusion 界面和 TraceCue 以 DIY 烧录页为视觉基准，保留各自流程与技术框架，不增加跨仓库运行时依赖。

## 规则

- 品牌：`#0b825c` 主操作、低饱和绿色底色、线性雷达标识。红色仍表示危险/错误，琥珀色仍表示警告，不把所有数据系列改成绿色。
- 排版：DM Sans / Noto Sans SC / 宿主字体 / 系统字体，无远程字体请求。紧凑 HA 卡片正文和控件 13 px，辅助文字至少 12 px，图内标注 11 px。标题字重 600；等宽字体只用于坐标、标识和代码。
- 层级：外卡片圆角 16 px，面板 14 px，输入框 10 px，使用轻边框与阴影。输入框、次要操作至少高 40 px，主操作 44 px；触控按钮至少 44 px。
- 每个 Lit Shadow Root 引入 `src/styles/controls.ts`，遵循 HA 的背景、文字与分隔线变量，不修改 HA 全局样式。宿主可用 `--mmwave-brand-color`、`--mmwave-font-family` 覆盖品牌色与字体。
- Canvas 使用 `src/styles/scene.ts` 的分类配色、字体和随主题变化的刻度/文字颜色。SVG 区域编辑器共用分类配色；热力图保留冷到热的语义色阶。坐标和校准计算不变。
- 保留键盘焦点、禁用状态、图标按钮可访问名称及减少动画支持。窄屏不能隐藏必要表单项。

## 覆盖与验收

覆盖实时卡片、配置编辑器、安装预览、几何/边界/区域编辑、方向校准、融合向导、联合校准、实时/回放/热力图控件和户型表单。Fusion 没有独立前端，界面在本仓库。原生 HA 实体选择器和集成弹窗仍由 HA 控制。

执行 `npm run lint`、`npm test`、`npm run build`（HACS 构建产物需同步更新）。无硬件验收可在本仓库运行 `python -m http.server 5176 --bind 127.0.0.1`，打开 `/test/visual.html`。页面使用真实构建与模拟状态，禁用设备写入。检查浅/深色、中/英文、390 px 与宽屏、键盘焦点、三步校准及融合配置模式。原生 HA 选择器/图标和真实设备写入仍需在 HA 中验收；模拟页不代表硬件兼容性已验证。
